Skill Health Badges

Anyone can publish an Agent Skill, so quality varies wildly. These badges are objective, automated checks run against each skill's real repository — the same spirit as an npm audit or an OpenSSF Scorecard, but for Agent Skills. A badge means a specific check passed. They measure conformance to this rubric, not whether a skill is good at its job.

The tiers

Gold

Passes all 6 checks.

Silver

Live repo, secret-free, and ≥4 of 6 checks.

Bronze

Live repo and secret-free — the minimum bar to import safely.

Unrated

Fails a base check (unreachable, or a secret was found).

The checks

BadgePasses when…

Checks are deterministic and offline (no LLM). Two — Actionable and SKILL.md — depend on directive extraction, so a skill with real instructions phrased unusually can still miss them. We label those as signals, not verdicts.
